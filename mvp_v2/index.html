Conceitos de Cloud

☁️ O que é cloud?

É usar computadores, armazenamento e bancos de dados de um provedor (como a AWS) pela internet, pagando só pelo que usar. Ela pode ser IaaS (você aluga a infraestrutura), PaaS (a plataforma está pronta para seu código) ou SaaS (o software já vem pronto).

A AWS fica espalhada em Regiões, e cada Região tem várias Zonas de Disponibilidade.
